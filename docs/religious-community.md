# P11 — عقد المجتمع الديني

مجال مستقل عن رسائل الجمعية وTelegram والموظفين. RELIGIOUS_COMMUNITY_ENABLED=false افتراضيًا؛ capabilities لا تعلن enabled إلا بعد وجود الجداول التسعة. لا تعديل .env ولا ترحيل قاعدة فعلية أو نشر ضمن التطوير.

مصدر migration: database/migrations/2026_10_26_150000_create_religious_community.php، بعد جداول الحساب وهوية P10. يحوي حسابات الإيقاف والحلقات والعضوية والمساهمات والمشاركات والإعجابات والحظر والبلاغات والمنشورات. العلاقات الدينية cascade عند حذف الحساب؛ لا حذف جدول أو سجل تابع للجمعية.

## المسارات

الأساس /api/v1/religious/community. الردود داخل data، والصفحات items/next_cursor مرتبة ID تنازليًا،20 افتراضيًا و50 أقصى. بوابة عامة60 طلبًا/دقيقة، ونشر10 وبلاغات5 مع مفاتيح مستقلة. الحساب الخاص ReligiousAccountOnly مع Sanctum؛ رمز موظف مرفوض.

## الملكية والتكرار

المساهمات في معاملة تقفل الحساب والحلقة، وإيصال متفرد للحساب وUUID. الحمولة المختلفة للمعرّف نفسه409، وإعادته بعد فقد الرد تعيد الإجمالي دون إضافة. لا تجاوز للهدف ولا مساهمة دون عضوية. الهدف تنظيمي، والنص من ReligiousCatalog المنشور بمصدره؛ لا Seed ديني جديد. بعد وجود مساهمات لا يمكن تبديل النص أو خفض الهدف عن مجموعها.

المشاركات تُنشأ في معاملة مع UUID متفرد للحساب. التعليق لا ينشأ تحت تعليق أو منشور غير ظاهر. الحظر متبادل للعرض والتفاعل، والموقوف لا يشارك أو يظهر في الخلاصة. المالك يرى المعلّق/المرفوض في أدعيتي. الحذف يُبقي tombstone وإيصالًا حتى حذف الحساب؛ لا يعيد retry نشره. النصوص الشخصية غير منسوبة للمكتبة، وكل عرض إداري escaped. البلاغ لا يمنح صاحبه قدرة مراجعة أو إيقاف.

الإدارة /admin/religious-community محمية بالويب ونوع User ودور superadmin وCSRF، ولها صفحات منفصلة للحلقات والمشاركات والبلاغات والمنشورات. قرار اعتماد/رفض وتعليق/استعادة مشاركة الحساب خادمي. لا اعتماد تعليق تحت أصل غير معتمد ولا إحياء tombstone. لا واجهة مستخدم عام لرفع الوسائط.

## النشر والوسائط

أنواع قرآن/حديث/دعاء/ذكر/تسبيح تعتمد نصًا منشورًا موثقًا من المكتبة، وتمنع وصفًا يستبدله. القرآن/الحديث يتحققان من نوع المصدر. فيديو MP4 أو YouTube ID من11 محرفًا، وروابط HTTPS دون بيانات دخول. رفع MIME JPEG/PNG/MP4 فقط حتى20MB، باسم يولّده التخزين؛ public/religious-community على قرص public. فشل الحفظ يحذف الملف الجديد فقط. إزالة المرجع لا تحذف ملفات سابقة قد تكون مستخدمة؛ تنظيف الوسائط عمل مدروس لاحقًا.

وقت النشر مطلوب للمنشور/المجدول، والانتهاء بعده، والمسودة لا تنشر نفسها. الاستعلام يقبل scheduled أو published بعد الموعد وقبل الانتهاء. الأمر religious-community:publish قابل للتكرار، مجدول كل دقيقة دون تداخل عند تفعيل الخدمة. هذا تعريف مصدر واختبار idempotence؛ لا cron أو queue أو Push حي جرى تشغيله. وسائط التخزين تحتاج URL عام HTTPS صحيحًا قبل تمكينها لعميل Flutter.
