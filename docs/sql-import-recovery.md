# إصلاح استيراد huk.sql على السيرفر

فُحص الملف المرفق في 14 أكتوبر 2026 دون تحميله في أي قاعدة بيانات. SHA-256 للأصل:

```text
3325108d985b42db7c5e7a8dca68ef5dc48ee74115e36c9241bc1cc9258fd02b
```

الملف يحتوي 66 جدولًا، و106 قيود مفاتيح خارجية، و367 سجلًا ضمن 11 جدولًا. يوجد سجل مستخدم واحد فقط في users. ثلاثون سجلًا من أصل 50 في categories تشير في created_by إلى المستخدمين 5 أو 11، وهما غائبان عن جدول users في الملف: 25 ارتباطًا إلى 11 وخمسة إلى 5. created_by يقبل NULL ويستخدم ON DELETE SET NULL.

أُنشئت نسختان منفصلتان في Downloads:

- `huk-server-fixed.sql`: نسخة استيراد كاملة، تتحول فيها تلك القيم الثلاثون فقط إلى NULL. تُستخدم عند الاستيراد إلى قاعدة فارغة. تحتفظ بكل الصفوف وبكامل تعريفات الجداول والقيود وبالقيم الأخرى.
- `huk-server-recovery.sql`: ملف لإكمال الاستيراد الذي توقف عند إضافة القيود، على نفس القاعدة المستوردة جزئيًا. يصلح الارتباطات التي لا يوجد لها مستخدم فعلي، ثم ينشئ كل قيد من الملف إذا كان غير موجود. لا يعيد إنشاء الجداول ولا إدخال البيانات، ويمكن استئنافه عند توقف التنفيذ. ليس مخصصًا لقاعدة فارغة.

اختر القاعدة `u227071417_hak` في phpMyAdmin ثم استورد recovery إذا كانت الجداول والبيانات قد وصلت إليها بالفعل. لا تستورد النسخة الكاملة فوق الجداول الموجودة. إذا أردت بدء الاستيراد من جديد، استخدم النسخة الكاملة في قاعدة فارغة بدل حذف قاعدة عاملة. خذ Export قبل تشغيل ملف الإصلاح إذا أضيفت بيانات للسيرفر بعد محاولة الاستيراد.

جوهر إصلاح البيانات:

```sql
UPDATE categories c
LEFT JOIN users u ON u.id = c.created_by
SET c.created_by = NULL
WHERE c.created_by IS NOT NULL AND u.id IS NULL;
```

يستعمل recovery INFORMATION_SCHEMA ثم PREPARE/EXECUTE لإضافة القيود الغائبة مع الحفاظ على ON DELETE الأصلي، بما يتفق مع [دعم MySQL للأوامر المحضرة](https://dev.mysql.com/doc/refman/8.0/en/sql-prepared-statements.html). لا يعطل FOREIGN_KEY_CHECKS ولا يحذف سجلًا أو جدولًا. العدد المتوقع عند اكتمال هذه النسخة هو 106 قيود، وforeign_key_checks يساوي 1؛ إذا وجدت جداول إضافية من إصدار أحدث قد يكون عدد القيود أكبر.

النسخة تعالج سلامة المفاتيح الخارجية المعرّفة فقط. لا تعوض المستخدمين أو البيانات غير الموجودة أصلًا في المصدر، ولا تصلح العلاقات polymorphic غير المقيدة بمفتاح خارجي.

التوليد والفحص بواسطة `tools/repair_sql_dump.py`، وهو محلل نصي يعمل دون SQL engine أو اتصال قاعدة بيانات. يرفض تعديل علاقة غير nullable، ويحافظ على الأصل ويرفض الكتابة فوق ملفات موجودة. التحقق أعاد صفر مخالفات عبر القيود المعرّفة، واحتفظ بعدد السجلات والقيود؛ اختبارات الاقتباسات والفواصل والحقول المطلوبة ناجحة. التنفيذ الفعلي على MySQL السيرفر لم يجر في هذه الجلسة.
