# إعداد إظهار روابط مصادر الترجمة

يوفر `GET /api/v2/admin/settings` و`PUT /api/v2/admin/settings` الإعداد `show_translation_source_links` مع `revision`. التغيير يتطلب جلسة الإدارة القصيرة وصلاحية `languages.manage` ونطاقًا عامًا فارغًا، ويسجل في `app_admin_audit` باسم `app.settings.updated`. يحفظ PUT رقم المراجعة المتوقع ويعيد 409 عند التعارض.

القيمة الافتراضية false. تنتقل القيمة العامة دون بيانات الحساب عبر `GET /api/v2/app-content/bootstrap`. لا يخفي تعطيل الروابط نسب المصدر النصي ولا يحذف أي مصادر أو ترجمات. لا تفعّل هذه الميزة لغات ولا تعتمد ترجمات ولا تنشر إصدارات.

## التحديث

بعد سحب `main` على السيرفر نفذ migration الإضافية فقط:

```sh
php artisan migrate --path=database/migrations/2026_11_02_180000_create_app_content_settings.php --force
```

هذه تضيف جدولًا مستقلًا صغيرًا، ولا تعدل جداول الحسابات أو المحتوى. قبل تنفيذها يظل bootstrap متاحًا ويعيد false؛ حفظ الإعداد يعيد 503 حتى تهيئة الجدول. لم تُنفّذ migration على قاعدة إنتاج أثناء التطوير.

داخل Flutter: لوحة الإدارة ← إعدادات التطبيق ← إظهار روابط مصادر الترجمة. يطبق العميل آخر قيمة ناجحة دون اتصال، مع رفض ردود أقدم، ويحدثها عند التشغيل والاستئناف. سجل الواجهة متزامن بين Laravel وFlutter للعربية والإنجليزية والتركية.

التحقق: `tests/Feature/HaqAppAccessTest.php` يختبر إخفاء الروابط افتراضيًا، الإظهار والإخفاء ورقم المراجعة والتدقيق، ومنع محرر المحتوى والأدمن المقيد بلغة. الاختبارات على اتصال SQLite `:memory:` المعزول داخل نفس الاختبار. سجل القبول `storage/logs/content-display-final-tests.log`: 31 اختبارًا و6607 تحققات؛ سجل مخطط الترجمة يفحص القيم والمعاملات والروابط. لم يُشغّل تحديث بيانات إنتاج.
