# دفعات الترجمة والمراجعة

التنفيذ على برانش `codex/haq-multilingual-admin`. حسب طلب المستخدم، لا يدمج الاستكمال الجديد حتى يكتمل العمل والفحص. أوامر التهيئة الأساسية في `app-localization-and-access.md`؛ هذه الدفعة لا تضيف migration ولا تشغل قاعدة الجمعية.

كل المسارات تحت `/api/v2/admin/languages/{locale}/translations`:

- `GET export?kind=ui&page=1`، أو `kind=content`: يصدر صفحة من 30 عنصرًا مع إجمالي الصفحات، الأصل، الاقتراح الإنجليزي إن وجد، القيمة المحفوظة ورقم مراجعتها. يعيد ملفًا خاصًا بالمراجعة وليس حزمة نشر أو أسرار حساب.
- `POST import`: يفحص كامل الدفعة ونطاق اللغة وصلاحية تعديل كل نوع، ثم يحفظ المسودات فقط عند طلب التنفيذ. حد 500 عنصر و5 MiB. العناصر المكررة والمفاتيح المجهولة والمتغيرات غير المطابقة مرفوضة.
- `POST review`: يتطلب صلاحية المراجعة. كل قيمة يجب أن تطابق المسودة المحفوظة مع رقم مراجعتها؛ لا يستطيع المراجع تغيير النص ثم اعتماده بنفس طلب المراجعة. الاعتماد لا ينشر اللغة.

مثال جسم طلب:

```json
{
  "dry_run": true,
  "package": {
    "format": "haq.translation.exchange",
    "schema": 1,
    "locale": "en",
    "records": [
      {"key": "ui/nav.home", "revision": 1, "value": "Home"}
    ]
  }
}
```

الفحص هو الافتراضي عند عدم إرسال `dry_run`. بعد قراءة الملف ونجاح الفحص، يعاد الطلب مع `dry_run=false` لتنفيذ العملية المطلوبة. تعارض عنصر يعيد `409` مع قائمة مفاتيحه، دون كتابة جزء من الدفعة. الاستيراد يلغي أي اعتماد سابق للنص المعدّل. الأصل القرآني العربي محمي في الفحص والحفظ، ولا تقبل حقول المراجعة الواردة في الملف كترخيص اعتماد.

في Flutter: من قائمة اللغة في اللوحة، افتح «استيراد وتصدير الترجمات». يمكن تصدير الصفحات ونسخ JSON إلى المترجم ثم لصق الملف الناتج. يطلب التطبيق فحص الوثيقة الحالية قبل تنفيذها؛ أي تعديل في النص أو تغيير وضع العملية يبطل الفحص السابق. وضع اعتماد المحفوظات ظاهر للمراجع فقط، وطلبات السيرفر تتحقق من صلاحياته الحالية. لا تنشر تلقائيًا بعد الاستيراد أو الاعتماد.

سجل الواجهة الحالي يحتوي **1283 مفتاحا** AR/EN، ويشمل الدليل والبداية والإعدادات والحساب والقرآن والصلاة والأذكار والمساعد والاشتراك والتنبيهات وأزرار الشاشة الأصلية وإدارة الدفعات ومراجعة مصادر الأحاديث. بعد رفع تحديث مفاتيح جديد، `php artisan haq-app:initialize` يضيف المسودات الجديدة دون الكتابة فوق الترجمات الموجودة أو اعتمادها. اكتمال هذا السجل لا يثبت استخراج جميع نصوص التطبيق أو اكتمال اللغات الـ33 الأخرى. مفاتيح المساعد تخص الواجهة ولا تغير لغة توليد الشرح أو سعر المتجر وبياناته.

لغة المحتوى مستقلة اختياريًا عن الواجهة، ومحفوظة على الجهاز. الافتراضي اتباع الواجهة؛ اختيار لغة محتوى لا يغيّر الواجهة. تبقى الحزمة النشطة محفوظة ولا تحذف أثناء استخدامها. موارد المحتوى ذات اتجاهها وإسنادها، والقرآن العربي المضمّن يبقى الأصل.
